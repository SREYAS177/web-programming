# Web Programming Lab Experiments

## About
This repository contains Web Programming laboratory experiments completed as part of the Master of Computer Applications (MCA) programme.

The experiments cover responsive web design, HTML, CSS, JavaScript, API integration, Flask and database operations.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Fetch API
- AJAX
- Python
- Flask
- SQLite

## How to Run

### HTML, CSS and JavaScript Programs
1. Open the required experiment folder.
2. Open the `index.html` file in a web browser.
3. Test the application using the available features.

### Flask Programs
1. Install Flask:

   ```bash
   pip install flask
   ```

2. Open the required experiment folder in the terminal.
3. Run the Python file:

   ```bash
   python app.py
   ```

4. Open the application in your browser:

   ```text
   http://127.0.0.1:5000/
   ```

## API Requirements
- **Experiment 11:** OpenWeather API key required.
- **Experiment 12:** NewsAPI key required.
- **Experiment 13:** Uses JSONPlaceholder API; no API key required.

Keep API keys private and do not upload them to GitHub.
