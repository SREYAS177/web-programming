# Web Programming Lab Experiments

## About
This repository contains the Web Programming lab experiments completed as part of the **Master of Computer Applications (MCA)** programme.

The programs demonstrate the use of HTML, CSS, JavaScript, Fetch API, AJAX, Python Flask and SQLite for developing interactive and dynamic web applications.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Fetch API
- REST API
- Python
- Flask
- SQLite

## How to Run

### HTML, CSS and JavaScript Programs
1. Open the required experiment folder.
2. Open the `index.html` file in a web browser.
3. Test the application using its input fields and buttons.

### Flask Programs

1. Install Flask:

   ```bash
   pip install flask
   ```

2. Open the required experiment folder in the terminal.
3. Run the Python file:

   ```bash
   python app.py
   ```

4. Open the following address in your browser:

   ```text
   http://127.0.0.1:5000/
   ```

## API Requirements

- **Experiment 11:** Requires an OpenWeather API key.
- **Experiment 12:** Requires a NewsAPI key.
- **Experiment 13:** Uses JSONPlaceholder API and does not require an API key.

Keep API keys private. Do not upload actual API keys to GitHub.

## Database
SQLite databases are created automatically when the Flask applications are executed.
